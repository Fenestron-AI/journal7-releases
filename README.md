# journal7-releases

Канал обновлений клиента **journal7** (Desktop SaaS для расчётчика энергосбыта).

Сюда CI репозитория `journal7` публикует артефакты Velopack: установщик Windows
(`Setup.exe`, портативный архив), AppImage для Linux, пакеты обновлений и манифесты
`releases.win.json` / `releases.linux.json`.

Вручную ничего скачивать не нужно: клиент сам проверяет обновления и предлагает
установить новую версию. Установочные файлы — во вкладке **Releases**.
